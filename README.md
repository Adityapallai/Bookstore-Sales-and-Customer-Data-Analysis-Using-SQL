# Bookstore Sales and Customer Data Analysis Using SQL

## Project Overview
This project focuses on analysing bookstore data using SQL to understand sales performance, customer purchasing behaviour, book popularity, and inventory management. It involves working with relational datasets containing information about books, customers, and orders to extract meaningful business insights.

## Project Objectives
- Analyse bookstore sales performance and revenue.
- Identify popular books and book genres.
- Understand customer purchasing behaviour.
- Identify top-spending customers.
- Analyse book availability and inventory levels.
- Generate business insights using SQL queries.

## Tools and Technologies
- SQL
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- GitHub

## Dataset Description
The project uses three datasets:

**1. Books Dataset**
- Book ID
- Title
- Author
- Genre
- Published Year
- Price
- Stock

**2. Customers Dataset**
- Customer ID
- Customer Name
- Email
- Phone
- City
- Country

**3. Orders Dataset**
- Order ID
- Customer ID
- Book ID
- Order Date
- Quantity

## SQL Concepts Used
- SELECT, WHERE and ORDER BY
- Aggregate Functions (SUM, AVG, COUNT, MIN, MAX)
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- CASE Statements
- Data Filtering and Sorting

## Business Questions
1. Identify the most expensive books in the bookstore.
2. Find books belonging to a particular genre.
3. Calculate the total number of books available in stock.
4. Identify the most popular book genres.
5. Calculate total revenue generated from book orders.
6. Identify customers who have placed the highest number of orders.
7. Find the top-selling books based on quantity sold.
8. Analyse customer purchasing patterns.
9. Identify books with low stock availability.
10. Calculate sales performance across different book categories.

## Project Outcomes
- Gained practical experience in relational database analysis.
- Developed skills in writing SQL queries to solve business problems.
- Learned to combine multiple datasets using SQL JOINs.
- Improved understanding of aggregate functions, subqueries, CTEs, and window functions.
- Developed an understanding of how SQL supports business decision-making through data analysis.

## Conclusion
This project provided hands-on experience in analysing bookstore data using SQL. By applying different SQL techniques, the project demonstrates how raw data can be transformed into meaningful information to understand sales performance, customer behaviour, and inventory management.
